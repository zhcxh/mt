# 中国房产研究方法论 (Chinese Property Research Methodology)

## 概述

从云端IP研究中国房产信息的完整方法论。基于2026-08-11对广州"一品湖山"和"望庐花园"的实战研究总结。

## 核心挑战

从非中国IP访问中国房产数据面临全面封锁：
- 百度、搜狗：CAPTCHA验证
- 贝壳/链家：IP封锁 + 行为分析
- 安居客/58：JS挑战 + CAPTCHA
- 房天下：区域路由 + bot检测
- Bing CN：中文编码问题导致结果无关

## ✅ 有效策略

### 1. 360搜索 (so.com) — 首选搜索引擎

**优势**: 不触发CAPTCHA（单次会话），支持中文，有AI摘要，整合360百科

**⚠️ 重要发现 (2026-08-11)**: 360搜索在**同一会话中多次搜索后会触发CAPTCHA**。建议：
- 单次会话控制搜索次数（3-5次以内）
- 如果触发CAPTCHA，切换到百度搜索
- 使用不同关键词组合，避免重复搜索

**搜索模板**:
```
# 基础搜索
browser_navigate(url="https://www.so.com/s?q=小区名+城市+区+地铁+公交+学校")

# 学区搜索
browser_navigate(url="https://www.so.com/s?q=小区名+对口学校+学区+户口")

# 地铁距离
browser_navigate(url="https://www.so.com/s?q=小区名+地铁站+距离+步行")

# 政府来源
browser_navigate(url="https://www.so.com/s?q=查询内容+site:gov.cn")
```

**结果解读**:
- AI摘要框：综合多个来源的结构化信息
- 360百科词条：楼盘基本信息（地址、地铁、户型、容积率）
- 安居客/搜狐焦点摘要：对口学校、房价、户型
- "为您推荐"：精准的中文长尾搜索词

### 2. 百度搜索 — 中国境内IP的最佳中文搜索

**关键发现**: 百度搜索**从中国境内IP（住宅/企业）可以正常使用**，不需要特殊绕过。

**使用方法**:
```
# 浏览器导航（推荐，完整渲染搜索结果）
browser_navigate(url="https://www.baidu.com/s?wd=搜索关键词")

# curl方式（可能被拦截，不如浏览器可靠）
curl -sL "https://www.baidu.com/s?wd=%E6%90%9C%E7%B4%A2%E5%85%B3%E9%94%AE%E8%AF%8D" \
  -H "User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36"
```

**搜索结果特征**:
- 搜索结果摘要包含**大量有价值数据**（数字、同比变化、政策引用）
- 很多时候**不需要点击进入文章**，摘要本身就包含关键数据点
- "大家还在搜"相关搜索词精准
- 热搜榜提供实时话题参考
- 结果来源标注（"官方"、"权威媒体"等）

**数据提取技巧**:
- 搜索结果中的 `<emphasis>` 标签包裹的内容通常是关键数据
- 摘要中的百分比、万亿/亿等数字可以直接引用
- 来源标注（"第一财经"、"央广网"、"财政部"等）可用于验证可信度
- 多次搜索不同关键词组合可以覆盖不同维度的数据

**⚠️ 注意**: 如果从海外/云端IP访问百度，会返回CAPTCHA或空结果。此时应使用360搜索 (so.com) 作为替代。

### 3. 政府/政协提案数据库 — 最精确的信息源

**关键发现**: 政协提案中的数据比任何房产平台都更精确。

**实例对比**:
| 信息 | 房产平台 | 政协提案 |
|------|---------|---------|
| 地铁距离 | "离地铁站较远" | "3.4公里" |
| 片区学校 | 列出部分 | 精确列出5所 |
| 人口数据 | 无 | "约7万居民" |
| 住宅区 | 部分 | 列出7个 |

**搜索方法**:
```
# 360搜索政府来源
browser_navigate(url="https://www.so.com/s?q=小区名+对口学校+site:gov.cn")

# 直接访问政协提案
browser_navigate(url="https://www.gzzx.gov.cn")
# 导航到: 提案工作 → 提案公开 → 搜索关键词
```

**政府信息源清单**:
- 广州市政协提案: www.gzzx.gov.cn
- 白云区政府: www.by.gov.cn
- 广州市教育局: www.gzeduc.gov.cn (学区划分)
- 广州市住建局 (房产政策)
- 同和街道办事处官网 (户口/社区)

### 4. 360百科 (baike.so.com) — 楼盘基本信息

**搜索方法**:
```
browser_navigate(url="https://baike.so.com/search/?q=小区名+城市")
```

**可获取信息**:
- 地址、开盘时间、户型面积

- 周边配套（学校、医院、银行）
- 项目优缺点
- 物业类型、建筑类型

### 5. 搜狐焦点 (focus.cn) — 对口学校确认

**搜索模板**:
```
# 360搜索 + site:focus.cn
browser_navigate(url="https://www.so.com/s?q=小区名+对口学校+site:focus.cn")
```

**关键信息**:
- 对口小学/初中（省一级/市一级）
- 房价走势
- 户型图和成交记录

### 6. 安居客问答 — 社区信息

**搜索模板**:
```
browser_navigate(url="https://www.so.com/s?q=小区名+site:anjuke.com+问答")
```

**可获取信息**:
- 地铁距离（居民实际体验）
- 学校对口确认
- 物业服务质量
- 周边配套实际情况

## 常见陷阱

1. **Bing CN编码问题**: 中文查询在Bing CN可能返回完全无关的英文结果
2. **360搜索curl空结果**: 浏览器方式比curl更可靠
3. **360搜索CAPTCHA**: 同一会话多次搜索后会触发CAPTCHA，需切换搜索引擎
4. **房产平台摘要≠完整信息**: 搜索结果中的摘要可能不完整
5. **学区每年微调**: 对口学校信息需要确认最新年度
6. **政协提案时间**: 提案数据可能不是最新的，需交叉验证
7. **地铁距离差异**: 不同来源给出的距离可能不同（直线vs实际步行）
8. **政府网站URL脆弱**: 政府文章URL经常404，应通过搜索结果点击进入

## 搜索引擎切换策略

当一个搜索引擎被阻止时，按以下顺序切换：

```
1. 360搜索 (so.com) → 首选，不触发CAPTCHA（单次会话）
2. 百度搜索 (baidu.com) → 中国境内IP可用，AI摘要优秀
3. 新浪新闻搜索 (search.sina.com.cn) → 最可靠的新闻搜索
4. 搜狗搜索 (sogou.com) → 可能触发CAPTCHA
5. 必应中国 (cn.bing.com) → 中文编码问题
```

**关键策略**: 
- 360搜索和百度搜索在**中国境内IP**都能正常使用
- 从**云端/海外IP**访问时，只有360搜索可靠
- 新浪新闻搜索**从不触发CAPTCHA**，是新闻/政策研究的最佳选择

## 实战案例: 一品湖山 (广州白云区)

**研究流程**:
1. 360搜索"一品湖山 广州白云区 同和路" → 获取基本信息
2. 360百科词条 → 获取地址、地铁、公交、学校、医院
3. 360搜索"一品湖山 对口学校 同和小学 学区" → 确认学区
4. 360搜索"一品湖山 同和地铁站 距离 步行" → 获取精确距离
5. 360搜索"白云区同和街道户口迁入条件" → 获取户口政策
6. 访问政协提案 → 获取最精确的地铁距离(3.4km)和片区数据

**最终结果**:
- 地铁: 3号线同和站，约3.4公里（政协提案精确数据）
- 公交: 296/504/502/560/862B/232/B6/839路
- 对口小学: 同和小学（省一级）或握山小学
- 医院: 南方医院(三甲)、157医院、同和职工医院
- 公园: 南湖国家旅游度假区、南湖游乐园
- 户口: 白云区有房+1年社保可申请入户

## 实战案例: 望庐花园 (广州白云区) — 配售型保障房

**背景**: 望庐花园是广州首个存量商品房转配售型保障房项目，备案名"望庐花园"，推广名"中海麓府"。

**研究流程**:
1. 360搜索"望庐花园 广州市白云区 地址 地铁 学校" → 获取基本信息
2. 360搜索触发CAPTCHA → 切换到百度搜索
3. 百度搜索"望庐花园 白云区 广云路 对口学校 周边配套 医院 商场" → 获取详细配套
4. 百度搜索"望庐花园 开发商 建成年份 总户数 物业费 中海麓府" → 获取建筑信息
5. 百度搜索"望庐花园 site:gov.cn 白云区 保障房" → 获取政府官方信息
6. 访问广州市人民政府网站 → 获取官方销售通告

**最终结果**:
- 地址: 广州市白云区广云路216号
- 地铁: 2号线江夏站、黄边站，直线距离约600米
- 对口学校: 黄边小学、江夏小学（具体以当年教育局划片为准）
- 幼儿园: 社区配建12班幼儿园
- 商场: 保利时光汇（5分钟步行）、云门NEW PARK、安华汇、白云万达广场
- 医院: 广州医科大学附属市八医院、广东省博济医院、嘉禾益民医院
- 物业费: 5.3元/㎡·月（商业）/ 约2元/㎡（保障房）
- 总户数: 468户
- 建筑类型: 1#楼40层、2#3#楼44层、5#楼41层（两梯三户）
- 开发商: 广州盛云房地产开发有限公司（中海地产全资子公司）
- 建成年份: 2025年9月
- 停车位: 821个
- 物业公司: 中海物业集团有限公司
- 销售价格: 基准价22,800元/㎡（范围: 18,240-27,360元/㎡）

**研究要点**:
1. 360搜索在第3次搜索后触发CAPTCHA，需切换到百度
2. 百度AI摘要提供了非常详细的配套信息，无需点击进入文章
3. 政府来源（gz.gov.cn）提供了最权威的销售信息和价格
4. 保障房项目需特别注意：对口学校以当年教育局划片为准，不自动继承原商品房学区
5. 同一项目可能有多个名称（备案名vs推广名），需交叉验证
