# 房产投资分析技能

## 功能概述

提供房产投资的完整分析方法论，包括三维评估框架、多因素分析、租售比计算、政策意图解读。当前以广州白云区一品湖山为案例。

## 🎯 触发场景

- 用户询问房产投资价值
- 用户要求计算租售比/租金回报率
- 用户要求分析购房政策、学区、交通
- 用户要求分析土地财政、收储资金等宏观因素
- 用户询问特定楼盘/小区的投资评估

## 📐 三维评估框架

### 维度一：政策层面 + 新楼盘售价

**分析要点：**
1. 购房政策（限购/限贷/首付比例/利率/契税/增值税）
2. 周边新盘价格 vs 二手房价格（新房-二手房价格差反映市场热度）
3. 区域去化周期（库存消化速度）

**关键信号：政策越宽松 = 市场越弱。取消限购、降低利率不是利好，是市场疲软的证明。**

### 维度二：二手房交易/租赁 + 租售比评估

**租售比计算公式：**
```
租售比 = 房价 ÷ 月租金（回本月数）
年化回报率 = (月租金 × 12) ÷ 房价 × 100%
```

**判断标准（用户指定框架）：**
| 租售比 | 年化回报率 | 判定 |
|--------|----------|------|
| ≥ 1:200 | ≥ 6.0% | 🟢 值得购买 |
| 1:200 - 1:300 | 4.0%-6.0% | 🟡 健康区间 |
| 1:300 - 1:500 | 2.4%-4.0% | 🟠 偏贵 |
| ≤ 1:500 | ≤ 2.4% | 🔴 租房更划算 |

**现金流倒挂分析：**
```
月供 vs 租金对比：如果月供 > 租金 → 每月在"倒贴利息"
年净现金流 = 年租金 - 年月供（负数=倒挂）
```

**需要采集的数据：**
1. 在售房源挂牌价（均价、中位价、按户型分类）
2. 实际成交价（近期成交记录）
3. 租赁挂牌价（月租金、每㎡租金）
4. 同区域/板块对比价

### 维度三：交通/户口/学区

**分析要点：**
1. 最近地铁站距离 + 公交接驳
2. 对口小学（省一级/市一级/区一级）
3. 周边医院、商业、公园
4. 户口/落户政策

## 📊 多因素分析

### 人口流动分析

**需要数据：**
1. 区域常住人口趋势（近5年）
2. 户籍人口 vs 流动人口比例
3. 人口净流入/流出

**流动人口占比高 = 租赁需求旺盛，但也意味着经济波动时需求不稳定。**

### 土地财政与政策意图分析

**核心逻辑：**
```
土地财政依赖 → 地方债务高企 → 房产泡沫风险
→ 国家转型：去土地依赖 + 挤泡沫 + 防风险
→ 工具：取消限购 + 降利率 + 收储转保障房
→ 信号：政策越宽松 = 市场越弱
```

**关键指标：**
- 土地出让金趋势（年同比下降幅度）
- 收储资金使用率（政府是否愿意在当前价位接盘）
- 地方财政负债率
- 库存去化周期

### 经济基本面

**需要数据：**
- 区域GDP及增速
- 居民可支配收入
- 新房/二手房去化周期

## 🔧 数据采集方法

### 租赁价格采集方法论

**租赁数据采集优先级（2026年8月实测）：**

| 优先级 | 数据源 | 优点 | 缺点 |
|--------|--------|------|------|
| 1 | **安居客小区页** | 社区均价+大量在租房源 | 需要浏览器访问 |
| 2 | 360搜索摘要 | 快速获取价格范围 | 数据可能过时 |
| 3 | 房天下租赁频道 | 有挂牌数据 | 动态class名，提取困难 |
| 4 | 幸福里APP | 有真实房源图片 | 需要APP或移动版 |

**安居客租赁数据提取方法（核心方法）：**

```javascript
// 方法1: 提取所有价格标签（strong标签包含价格）
const strongs = document.querySelectorAll('strong');
const listings = [];
strongs.forEach(s => {
  const priceText = s.textContent.trim();
  if (priceText.match(/^\d{4,6}$/)) {
    let parent = s.closest('[class]');
    let attempts = 0;
    while (parent && attempts < 10) {
      const t = parent.textContent.replace(/\s+/g, ' ').trim();
      if (t.includes('平米') && t.includes('室') && t.length < 600) {
        listings.push({price: parseInt(priceText), context: t.substring(0, 400)});
        break;
      }
      parent = parent.parentElement;
      attempts++;
    }
  }
});

// 方法2: 提取社区均价（页面顶部统计）
// 安居客小区页顶部显示"本月整租均价：三室 14,546元/月"
```

**安居客租赁页面结构：**
```
URL: https://gz.zu.anjuke.com/community/search/?kw=小区名
页面顶部: 社区均价统计（一室/二室/三室/四室）
列表项: 标题 | 户型 | 面积 | 楼层 | 小区名 | 朝向 | 地铁 | 价格
```

**租赁数据采集清单：**
1. 社区月度整租均价（安居客小区页顶部）
2. 各户型在租房源数量
3. 各户型价格范围（最低/最高/中位数）
4. 每㎡租金（月租金÷面积）
5. 朝向/楼层对价格的影响
6. 精装修vs简装修的价格差

**研究流程**:
```
1. 360搜索"小区名 城市 区 地址" → 获取基本信息
```

**核心瓶颈（使用率低的原因）：**
- 价格错配：收储价约为市场价50%，开发商不愿卖
- 供需错配：库存集中在三四线，需求在一二线
- 租金回报低：~2% 租金收益 vs ~3.65% 贷款成本
- 银行意愿低：再贷款利率仅1%利差
- 资金缺口大：天风证券估算需~7万亿，现有资金只是零头

## ⚠️ 分析注意事项

1. **挂牌价 vs 成交价差距大（~30%）**：说明市场议价空间大，买方市场
2. **租售比全面低于1:500**：所有场景均不达标，租房更划算
3. **政策信号**：取消限购+降利率+收储资金闲置 = 市场疲软
4. **人口结构**：流动人口占比高，需求旺盛但不稳定
5. **现金流倒挂**：月供是租金的2倍，每年倒贴4-5万
6. **唯一亮点**：低密度+省一级学区，自住品质好

## 🔍 分析模板

执行房产分析时，按以下顺序：

```
1. 采集售价数据（房天下/360搜索）
2. 采集租赁数据（房天下/360搜索）
3. 计算租售比（5个场景）
4. 计算现金流倒挂（3种利率）
5. 对比无风险利率（银行定存/理财）
6. 查询政策（限购/利率/收储）
7. 查询学区/交通/配套
8. 查询人口/经济数据
9. 查询土地财政/收储资金
10. 综合判定投资价值
```
